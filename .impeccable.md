# openculturemap — Impeccable design context

## Design Context

### Users
General-public, open-ended cultural-discovery audience. No specific trip in mind — people landing here want to *wander* Europe's cultural fabric the way you'd wander a museum without a guidebook. Sessions are exploratory and serendipitous, not goal-directed. Casual browsers and OHM-curious visitors alike. Device mix skews desktop / large screens for the main browsing experience, but mobile must remain a first-class adapted view (not a stripped one).

### Brand Personality
Three words: **Playful · Generous · Vivid**. Tone is "a children's history book reimagined for adults": bright but tasteful, characterful, illustrative, easy to share. The interface should feel like a wunderkammer atlas — an object you want to leaf through — not a database UI or an admin dashboard. Emotional goal: *curiosity and warmth*, not authority or efficiency.

### Aesthetic Direction
- **Inspirations**: Are.na / Cabinet magazine (editorial, archival, image-led, generously spaced); Stamen / Mapbox showcase maps (let the map breathe, cartography is the hero); Europeana for its image-richness — but explicitly *avoid* its institutional staleness.
- **Anti-references**: openstreetmap.org default UI, overpass-turbo, umap, any "generic OSM viewer" look. Flat, utilitarian, gray-on-gray, dense-form chrome — all forbidden.
- **Visual register**: a 19th-century printed atlas reimagined for the web. Warm paper feel in light mode; deep ink with a cinematic warmth in dark. Earth-toned but vivid palette — terracotta, cobalt, saffron, moss — never neon, never cyan-on-dark.
- **Theme**: both light and dark, with a visible toggle. Default to **light** (paper/atlas — matches the wandering-by-day mood and the editorial inspiration). Dark mode is the evening-armchair variant.

### Design Principles
1. **The map is the hero — the chrome is the caption.** Sidebar and controls should feel like the margin notes of a printed atlas: present, useful, never competing with the cartography.
2. **Characterful typography over neutral system type.** A distinctive display serif for headings, a generous reading serif for body. Hierarchy through size and weight contrast, never through gradient fills.
3. **Earthy-vivid, not bright-loud.** Saturated accents drawn from earth pigments (terracotta, ochre, moss, ink, cobalt). 60-30-10 rule: paper / ink-and-borders / one warm accent. Never neon, never cyan-on-dark.
4. **Decorative details should look hand-set, not Figma-stock.** Where icons or marks appear, they should feel illustrative — small woodcut-ish glyphs, an asymmetric compass rose, era-appropriate ornaments. Avoid generic rounded-square icons and AI-stock decoration.
5. **Generosity of space.** Cabinet-magazine generosity in sidebar/section spacing. Cap reading widths at ~70ch. Use whitespace as a design element, not a default.
6. **Bans (project-specific reinforcement of skill bans):** no border-left accent stripes, no gradient text, no glassmorphism, no cyan/purple/blue-to-purple gradients, no glowing accents on dark, no monospace as "tech-y" shorthand.

### Typography Commitments
- **Display**: a characterful contemporary serif with personality (e.g. *Caprasimo* / *Young Serif* / *Gambarino*). NOT Fraunces, Playfair, Cormorant, DM Serif, Instrument Serif, or any other reflex pick.
- **Body**: a generous, slightly-warm reading serif (*Vollkorn* / *Spectral* / *EB Garamond*). NOT Inter, DM Sans, Plus Jakarta, Outfit, system-ui as a default.
- **No monospace** unless we ever surface code-like content. Numbers in the body face with tabular-nums OpenType feature where alignment matters.

### Color Commitments
- Use OKLCH everywhere.
- Light theme: warm off-white paper background (~98% L, ~0.01 chroma toward 80° / warm yellow), ink-warm text (~20% L), terracotta primary accent (~58% L / 0.16 C / ~35° hue), cobalt secondary (~50% L / 0.13 C / ~240°), saffron tertiary (~70% L / 0.15 C / ~80°), moss for heritage (~52% L / 0.10 C / ~140°).
- Dark theme: deep warm ink background (~15% L / 0.012 C / 75°), aged-paper text, the same accents tuned upward in lightness and downward in chroma to read correctly on dark.
- Neutrals are tinted toward the terracotta hue, not pure gray.
